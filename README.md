# Film Lab

Film looks for Galaxy S24 Ultra photos — Fujifilm simulations and Kodak films — in the browser, on a computer or a phone.

**Open:** https://ahmadziadah00-hub.github.io/filmlab/

- Your photos never leave your device. They are developed in your browser, and your edits are kept in this browser.
  To move edits to another device: *Presets → Session file → Save session*, then *Open session* there and add the same photos.
- **Install it** from the start screen (*Install Film Lab as an app*) or the browser menu (*Install app* / *Add to Home screen*).
  After the first visit it works without a connection.
- **Fujifilm simulations** aren't published here. Load your own Fujifilm pack file once in each browser (film list → *Load Fujifilm pack*).
  Simulation icons work the same way: add your own files.
